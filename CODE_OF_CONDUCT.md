# Code of conduct

SwitchDesk follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks aren't accepted in issues, pull requests, discussions or anywhere else in this project.

To report a problem, email [jaba@clihero.com](mailto:jaba@clihero.com). Reports are handled privately.
